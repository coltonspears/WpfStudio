# Counter sample

Open `CounterApp/CounterApp.csproj` in WpfStudio. Build the app, open `CounterViewModel.cs`, place a breakpoint on either `Count++` line, then start debugging. Click the matching button in the sample window to inspect locals, watch `Count`, and step through the command.

Use WPF Explorer to navigate `AccentBrush` and its usages. Preview renaming the key, save the affected files, and rebuild. The sample requires only .NET 10 and CommunityToolkit.Mvvm; it does not connect to a database.
