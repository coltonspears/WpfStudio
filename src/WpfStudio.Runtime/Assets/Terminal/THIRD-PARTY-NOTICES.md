The terminal renderer bundles the following open-source MIT-licensed packages, obtained from the npm public registry distribution via unpkg. It makes no network requests at runtime.

- `@xterm/xterm` 6.0.0 — https://github.com/xtermjs/xterm.js — `LICENSE-xterm.txt`
- `@xterm/addon-fit` 0.11.0 — https://github.com/xtermjs/xterm.js — `LICENSE-addon-fit.txt`
- `@xterm/addon-search` 0.16.0 — https://github.com/xtermjs/xterm.js — `LICENSE-addon-search.txt`

Microsoft Edge WebView2 is the Windows rendering runtime and is discovered locally; it is not bundled. The SDK NuGet package carries its own Microsoft license. Windows ConPTY is the OS pseudoconsole API.
